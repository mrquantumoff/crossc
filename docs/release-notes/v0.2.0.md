## crossc 0.2.0

**Unified volume.** The Windows volume slider now sets the buds' own volume, and a volume gesture
on the buds moves the Windows slider: one volume control instead of two. Play/pause/next from the
buds work as before.

* The playback device has a hardware volume and mute, and provides the volume interface that
  Windows' own AVRCP service drives for its inbox Bluetooth audio driver. Windows sends the level
  to the buds as AVRCP absolute volume; audio is streamed unscaled.
* If nothing drives that interface (for example after a Windows change), `crossc-service` applies
  the volume in software instead, as 0.1.x did.
* Kill switch: registry value `DisableAvrcpVolume` (see `docs/SETUP.md` section 14) restores the
  0.1.1 behaviour.
* Driver/service protocol v3. Install the driver and the service from the same release.

Tested on Galaxy Buds4 Pro on Windows 11: slider and buds volume move together. Includes the
crash-review fixes from 0.1.1. Still a test-signed driver: read "Before you install" in the README.
